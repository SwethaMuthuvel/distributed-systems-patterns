# Patterns of Data Partitioning
Data partitioning is a technique used to divide data across multiple machines so that a system can store more data, handle more requests and scale efficiently.

## Why Data Partitioning?
- Store large amounts of data
- Distribute workload across servers
- Improve scalability
- Avoid a single machine becoming a bottleneck
